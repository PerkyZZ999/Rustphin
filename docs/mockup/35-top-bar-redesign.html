What changes, in numbers

  • Title bar 36 px, drawn by Rustphin: logo, centred window title in body-md muted, Minimise / Maximise / Close at 44 × 36 px; Close turns red under the pointer. Drag to move, double-click to maximise, right-click for KDE's window menu, edges resize.
  • Toolbar 44 px, full width (was 52 px above each pane): 32 px icon buttons without outlines (hover fill), separated into groups by 20 px hairlines: administrator · Back, Forward, Up, Reload · location · New folder · view mode (one segmented control) · Split, Show hidden, Filter · Actions.
  • Toggles that are on (Split, Show hidden, the current view mode) take primary-subtle with a primary-bright icon; their tooltips and accessible state say "on" too, so state is not shown by colour alone.
  • Tab strip 36 px, now above the files only, beside the places panel; the places title row is 36 px to line up with it.
  • Rows 32 px (was 36), headings 28 px, places rows 28 px with 16 px icons, device rows 48 px, status line 28 px.
  • Split view: one toolbar for the active side; a 28 px path bar above each side.
  • Administrator mode: red shield, a 36 px error-coloured bar with a Stop button, "(administrator)" in the title.

Questions for the maintainer

  • Is this density right with the smaller text, or should rows stay 36 px?
  • Toolbar buttons without outlines (as here) or with them (as the W-079 toolbar)?
  • In split view, are the per-side path bars wanted, or should the toolbar's location be the only one?
  • Window buttons: minimise, maximise and close as drawn, or follow KDE's button order setting?
