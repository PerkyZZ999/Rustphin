Properties in tabs

Properties opens as a window of its own (D-041), 560 × 680 and resizable down to 440 × 480, like Settings: Rustphin's title bar, or KWin's when Settings › Appearance › Title bar says so. One window per file; several can be open. The tabs are a row of segments with Lucide icons; Ctrl+Tab and Ctrl+Shift+Tab move between them, and the current one has the accent edge besides its brighter words. A folder has General and Permissions only; Checksums and Details are for files.

Permissions, its page scrolling when the window is shorter, with Others just set to Forbidden (accent outline until applied) and Advanced open. Each choice sets Read and Write together; a mix the choices cannot say (write without read) reads "Custom" and shows Advanced open. The Group list holds the groups the user belongs to. Apply runs the changes through the operation engine, undoable like any operation; the footer says how many wait. On a folder, Execute reads "Allow entering the folder", plus "Apply to everything inside".

Checksums. Each is calculated only when asked, on a worker thread, with its progress and Stop; closing the window stops it. A pasted value of 32, 40, 64 or 128 hexadecimal digits picks MD5, SHA1, SHA256 or SHA512 and calculates it. A match is said in words with a check icon; a mismatch in `error` with an alert icon: "Does not match the SHA256 checksum: the file differs from the one the website describes. Download it again." Anything else pasted: "This is not a checksum Rustphin knows (MD5, SHA1, SHA256 or SHA512)."
