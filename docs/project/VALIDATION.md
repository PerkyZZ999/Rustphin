### 2026-11-10 — W-098a kio-admin helper client
- **Code:** `rustphin-platform::admin`. `decode_entry` reads KIO's `UDSEntry` as `QDataStream` writes it (32-bit count, per field a 32-bit id and a 64-bit number or a UTF-16 string, big-endian; at most 512 fields; nothing beyond the input is allocated; trailing bytes refused). `AdminEntry` keeps name, kind (a link destination marks a symlink), size, permission bits, times with nanoseconds, owner ids and names, device and inode. `admin_url` sends only absolute UTF-8 paths without `..`, U+FFFD or NUL, normalised and percent-encoded. `AdminHelper` talks to `org.kde.kio.admin` on the system bus: one reader thread forwards the helper's signals; each command (one at a time) calls the method, starts the command object, takes only that object's signals and waits at most 120 s; a refusal is `Denied`, KIO's error numbers map to standard error kinds; writes go in 1 MiB pieces answered to `dataRequest`, ended by an empty piece, never replacing a file; reads stop at 256 MiB.
- **Format evidence:** the test samples were written by KIO 6.31 itself (a throwaway C++ program serialising `KIO::UDSEntry` exactly as kio-admin's `dbustypes.cpp` does). The helper's methods and signals were read from kio-admin's source; no call was made to the real helper (it would ask for the maintainer's password).
- **Tests:** 13 in `admin::tests`: KIO's samples decode as KIO meant; every truncation, trailing bytes, impossible counts, unknown field kinds and bad strings are refused; unsafe paths are refused and never sent; error kinds; against a fake helper on a private bus: a listing (with a stray late result from an abandoned command ignored), a description, a write in pieces ending with an empty one, rename flags, refusal, a KIO failure with its message, a timeout. Mutations: the replace flag value, and removing the per-command signal filter, each failed tests; dropping the UTF-8 check alone survives because the replacement-character check also refuses such names.
- **Fuzzing:** new `admin_entry` target (seeds: the KIO samples); `rust-tc fuzz admin_entry 60` ran 1,201,306 inputs in 61 s without a failure.
- **Gate:** `rust-tc doctor` PASS.
